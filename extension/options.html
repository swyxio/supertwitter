SuperTwitterLocal connector

Connected accounts

Authorize each X account once to switch between them in SuperTwitter. The extension keeps your tokens in this Chrome profile and sends them directly to X.

    Connect an X account

    In the X Developer Console, enable OAuth 2.0 on a Native App or Single page App with read and write access. Your app needs X API access for the features you use.

    Register this exact callback in your app’s user authentication settings. Use https://x.swyx.io for the website URL.

    To add another account, select it on X before authorizing. Your existing connected accounts stay available here.

    Site access

    Allow these sites to display connected accounts and feeds. You confirm each change to X in this extension.
